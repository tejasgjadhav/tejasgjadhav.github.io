# AI in Finance Crash Course

Companion site for the book **AI in Finance: The Complete Crash Course** by Tejas Jadhav, CFA, FRM.

Live at https://tejasgjadhav.github.io/AIFinanceCrashcourse/

- `slides/` teaching decks, one per module
- `labs/` the runnable lab scripts from the book (public data, no API key needed)

Education only. Not investment advice. Every figure in the labs is a backtest, a simulation, or a
constructed example, and is labelled as such on the line where it appears.
