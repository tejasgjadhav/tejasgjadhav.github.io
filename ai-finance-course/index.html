AI in Finance Crash Course

The slides and the runnable labs that go with the course AI in Finance: The Complete Crash Course.

Everything here is free and needs no API key. The labs run on public data: SEC EDGAR for filings and Yahoo Finance for prices. You need Python 3.9 or newer and about ten minutes per lab. The language-model steps print the exact prompt if you have no model connected, so you can paste it into any assistant.

What this is

These are the slides and labs from a course that is actually taught, not a set of files made to go with a reading list.

The ten modules here are the ten sessions of an elective taught to postgraduate finance students. Each session runs for three hours. The deck on this page is the deck used in class, and the lab is the thing the students build.

You do not need a finance degree, and you do not need to code. Every finance term is explained the first time it appears. Every lab is a short Python script, printed in full and explained line by line. If you would rather not run code, each lab prints the exact prompt so you can paste it into any free AI chat and get the same result by hand.

The results are shown as they came out, including the failures. The trading lab backtests a rule that loses to the index. The valuation lab prints a model's commentary that is fluent, confident and wrong, with the engine's own answer beside it. A page that only shows its successes cannot be told apart from a slide deck.

Start here

Download the labs, install the three libraries, run the first script.

The whole lab folder is one zip file, 62 KB, holding every script and the dated data snapshots. You can also take any single script from the table below. Unzip it and run this.

cd labs
pip3 install yfinance pandas numpy requests
python3 m01_edgar_pnl.py AAPL

Or run four of the labs in this browser tab, with nothing installed. The live labs load Python into the page and read a dated snapshot of the same public data. The code pane is editable and the Run button executes what is in it.

How the labs behave

Three rules hold across every script here.

The arithmetic happens in Python, not in the model. Every number you see was computed by code you can read. The language model writes sentences about those numbers and nothing else.

Every figure is labelled. A backtest says it is a backtest. A simulation says it is a simulation. A constructed example says so on the same line. Nothing here is a live track record, and nothing here is investment advice.

The browser labs match the course. The downloadable scripts will not. Each lab on this site reads a stored snapshot, so it prints the same figures the course prints and you can check one against the other. The scripts in labs/ pull the most recent data at the moment you run them, so their numbers move. The course quotes one dated run so you can see the shape of the output.
