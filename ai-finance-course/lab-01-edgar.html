The income statement that checks itself

Pull three years of Apple's income statement out of an SEC EDGAR snapshot, print it in millions, then recompute two subtotals and mark each one PASS or FAIL.

← All live labs

This page runs Python in your browser. Nothing is installed and nothing is sent anywhere. The code below is the same code as labs/m01_edgar_pnl.py, with the network call swapped for a file that is already on this site.

What the lab does

The script runs four steps, in the order they appear below.

The script reads the SEC's XBRL company facts for one filer. It keeps only the rows that came from a Form 10-K, carry a full-year period, and sit on a clean twelve-month frame. It picks the three most recent fiscal year ends that have a revenue figure. Then it prints the statement in millions and recomputes two subtotals in Python.

The two checks are the point of the lab. Net sales minus cost of sales should equal gross margin. Gross margin minus total operating expenses should equal operating income. If either check says FAIL, the table is wrong and you do not use it. A language model reading the same filing would never tell you that.

This is a dated snapshot, not live data. The file behind this page is data/aapl_companyfacts_slim.json, taken on 20 September 2026, trimmed to the income-statement tags. Apple's last fiscal year in it ends 27 September 2025. To run the same lab against live EDGAR data on your own machine:
python3 labs/m01_edgar_pnl.py 320193

What you should see

The course quotes one run of this lab. Module 1 prints this table.

Fiscal year ended                         2023-09-30    2024-09-28    2025-09-27
Net sales                                    383,285       391,035       416,161
Cost of sales                                214,137       210,352       220,960
Gross margin                                 169,148       180,683       195,201
Research and development                      29,915        31,370        34,550
Selling, general and administrative           24,932        26,097        27,601
Total operating expenses                      54,847        57,467        62,151
Operating income                             114,301       123,216       133,050
Provision for income taxes                    16,741        29,749        20,719
Net income                                    96,995        93,736       112,010

All six checks pass. The page above reproduces that table digit for digit, because the snapshot was taken after Apple's FY2025 10-K was filed and EDGAR does not restate a filed figure.

Switch the dropdown to Microsoft and one line changes behaviour. Microsoft does not tag SellingGeneralAndAdministrativeExpense in its company facts, so that row prints not tagged and both subtotal checks still run on the lines that are there. That is the honest result, and it is what you want a checker to do. A model asked to fill the gap would have written a number.
