Live labs

Four labs from the book, running in your browser on dated snapshots of the real data. Nothing to install and no API key.

← Back to the course

Every lab on this page runs real Python. The pages load Pyodide, which is CPython compiled to WebAssembly, pinned to version 314.0.7. The code pane is editable and the Run button executes what is in it. Nothing you type leaves your machine, and no lab makes a network call once the page has loaded.

The four labs

Each one reads a snapshot in data/, prints its own as-of date, and reproduces the figures the book prints.

ModuleLabWhat it does
01The income statement that checks itselfReads Apple's SEC EDGAR company facts, prints a three-year income statement in millions, then recomputes gross margin and operating income and marks each one PASS or FAIL. Switch the dropdown to Microsoft and watch a line print not tagged instead of a guess.
04A 20-day breakout, tested honestlyRuns the 20-day breakout and 10-day exit rule on two years of SPY daily prices, long only, with costs at 5, 10 and 20 basis points. Prints the monthly table, the summary, and the closed round trips. The window and both lookbacks are yours to change.
05Ten thousand simulated daysMeasures the mean and covariance of five US large caps, Cholesky-factors it, draws 10,000 correlated one-day outcomes, and reads the 95% and 99% VaR and CVaR off the sorted list. The seed is fixed at 42 and printed, so the page gives the same answer every time.
08The NAV pack that refuses to release itselfPrices a constructed five-holding fund, computes NAV per share, and runs three checks: a missing price, a stale date and a move over 5%. Tick Inject an error and the status line flips to HELD, the way it does in the book.

What is not here, and why

Six labs in the book do not appear on this page. Four of them need a language model.

A browser can run Python. It cannot run a language model that you have not paid for and connected. These four steps are the ones where a model does the work, so they stay in the downloadable scripts and in the book:

ModuleThe step that needs a modelWhere to get it
02The retrieval answer. The lab builds a searchable index over a 200-page IPO prospectus, then asks a model to answer a question and cite the page it came from. The retrieval half is code. The answer half is the model.ingestqueryquestions
03The investment memo. Three agents hand work to each other and the third one writes the memo. Every hand-off is a model call.m03_three_agent_memo.py
07The prompt-injection test. You feed a document carrying a hostile instruction to a model and watch whether it obeys the document or the operator. There is nothing to test without the model.In the book, Chapter 7
09The morning commentary. The dashboard computes the numbers and the model writes the sentences about them. The exercise is catching it when it invents a figure that is not in the table.m09_dashboard.py

Two more are missing for duller reasons. Module 6 writes a Word file, which is a download rather than a page. Module 10 is the capstone, and it assembles the other nine rather than adding a new one.

If you want those four, download the lab folder and run them locally with a model of your choice. Every script prints the exact prompt it would send when no model is connected, so you can paste it into any assistant and get the same result by hand. The whole lab folder is one zip file, 62 KB.

How these pages work

Three things are worth knowing before you trust a number one of them prints.

The data is a dated snapshot. Each lab reads a file in data/ that was pulled once, on 20 September 2026, and frozen. Every page prints that date at the top of its output. The snapshot is what makes the pages reproducible, and it is also what makes them wrong about today. Each page carries the one-line command that runs the same lab against live data on your own machine.

The numbers do not always match the book. Where they differ, the page says so, names the figure, and gives the reason. Lab 4 differs because the snapshot carries unadjusted closes and the book's run added dividends back. Lab 5 differs because the snapshot's window is three weeks shorter at one end and three weeks longer at the other. Lab 8 differs because the snapshot holds a different fund. Lab 1 matches digit for digit, because a filed 10-K does not change.

The arithmetic happens in Python. Every number these pages print was computed by code you can read and edit in the pane. Nothing on this page was written by a language model, and nothing here is investment advice.
